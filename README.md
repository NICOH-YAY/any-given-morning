# Any Given Morning

A small farm, a small day, and about twenty seconds.

**Play it:** https://nicoh-yay.github.io/any-given-morning/ (live once GitHub Pages is on)

You wake on an ordinary morning in a pixel farm. You can wander, talk to people, help someone, or do nothing. Then something absurd ends the day, and a new morning starts somewhere else with different people. Five lives make a round.

One switch on the menu changes the game. **Mortality** on: every life ends after 16 to 24 seconds, whatever you do. Mortality off: the same worlds, but you live through a 100 second day. Play both and notice what you did.

Controls: WASD or arrows to move, E, Space or Enter to interact, Esc for the menu. Touch devices get an on-screen pad.

## Run it locally

```bash
npm install
npm run dev
npm run build
```
